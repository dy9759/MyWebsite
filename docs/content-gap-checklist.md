## 素材提交规范

1. 截图统一使用 PNG 或 WebP，宽度至少 1600 px。
2. 数据图必须标记时间范围、样本量和指标口径。
3. Demo 链接需提供访问说明和预期结果。
4. 所有用户数据、内部域名、Token、客户名称和未公开收入必须脱敏。
5. 中文素材与英文素材使用相同事实，只翻译表达，不分别维护数字。
