## 内容治理规则

1. 未经本人确认的任职、教育、项目角色和指标不得公开。
2. 缺少证据时显示“待补充”，不使用推测数字。
3. 未来目标必须标记为计划，不得写成已经发生的经历。
4. 指标必须说明统计时间、分母、样本范围与口径。
5. 外部链接缺失的资源默认不展示；链接失效后先隐藏再核验。
6. 每次内容更新必须通过测试、Lint、类型检查与静态构建。

## 每月维护

- 月初：核对目标、DDL 与缺口清单。
- 月中：补充一个可验证证据（截图、数据、Demo 或公开文章）。
- 月末：检查外部链接、案例指标日期、简历版本和中英文一致性。
